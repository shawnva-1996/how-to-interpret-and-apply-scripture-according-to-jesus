# How to Interpret and Apply Scripture According to Jesus — Ed Lapiz

A bilingual reading edition of Ed Lapiz, *How to Interpret and Apply Scripture According to Jesus* (Deeper Water Series no. 18, CSM Publishing, 2017).

- **Original language kept intact:** the book as published, in Taglish (Filipino/English).
- **English translation alongside:** each section is followed by an English translation for non-Filipino readers.
- **Personal and educational use only.** Published with the user's stated written permission. The copyright page in the book states: "No part of this book may be reproduced in any form whatsoever without written permission from the copyright owner."
- Scripture quotations are from the Contemporary English Version Bible unless marked NIV.

## Contents

- `index.html` — Books-style web reader (section-by-section, Original / English / Bilingual, font size, light / sepia / night themes, arrow-key navigation).
- `book.json` — the bilingual text in machine-readable form, used by the reader.
- `book/how-to-interpret-and-apply-scripture-according-to-jesus-bilingual.md` — full bilingual text.
- `book/how-to-interpret-and-apply-scripture-according-to-jesus-original.txt` — cleaned OCR of the original.
- `book/original-scan.pdf` — the scanned PDF is **not** stored via the GitHub connector (it handles text files only). Add it here manually via GitHub's web upload if you want it in the repo; the EPUB download is provided separately.

## OCR note

The source PDF was a scanned image PDF (82 pages, no embedded text). Text was OCR'd with RapidOCR, cleaned (running headers removed, hyphenated Tagalog compounds kept, e.g. nagkakamali-mali), and proofed against obvious typos. A few passages were garbled in the scan and are best-effort reconstructions: the Mark 2:23–28 and Mark 3:1–6 quotations, one counsel section mid-book, the Deeper Water contents numbering, and the back-cover "Deeper Water" paragraph.
